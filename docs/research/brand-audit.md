# Brand audit

## What is already defined (keep it)

**Logo** (`assets/brand/ihs-logo-substack.png`, transparent versions in the same folder).
A **double-headed eagle** with **stepped wings**, a **Latin cross** on its chest and the letters **IHS** below. It packs three readings into one mark:

1. **Habsburg double-headed eagle**: the Spanish Empire of Charles V.
2. **Stepped "Aztec" eagle** of the United Farm Workers (César Chávez): the Chicano/US-Hispanic eagle. Exactly his target audience.
3. **IHS Christogram** (Jesuit monogram) = **I**nstitute for **H**ispano **S**tudies.

Strong, simple, works in one colour and at small sizes. Perfect for merch. We only need a proper vector (it only exists as a 1280 px PNG).

**Palette.** Burgundy `#470B15` on cream `#F9F3DD`, used consistently on Substack, Instagram avatar (with a gold ring) and the website theme.

**Type (website).** Ibarra Real Nova (a revival of Joaquín Ibarra's 18th-century Spanish types: on-theme) + Inter.

**Hidden symbol.** His tagline ends with `𓃓 𖤓`: Egyptian hieroglyph E002 (a **bull**) and Bamum letter NGKYEE, which looks like a **sun**. Bull + sun: Iberia + the empire where the sun never sets? Ask him what it means; it could become a secondary mark.

**Mottos.** "Veritas prius pace" (truth before peace), "Baroque Modernity", "Hispanorientalism".

## What is not defined (opportunity)

| Gap | Evidence | Proposal |
| --- | --- | --- |
| Name | "Institute for Hispano Studies" vs "Hispanic American Studies" (Substack subtitle, Patreon handle) | One name, one handle everywhere |
| Social visual language | Instagram mixes YouTube-style thumbnails (thick green/red outlined text) and parchment quote cards. Neither uses the burgundy/cream of the logo | Templates for thumbnails, quote cards and carousels in the brand system |
| Type system | Only on the website; nothing on social | Display + text + mono, with rules |
| De Indiis Editions | No mark, no cover system | Imprint mark and book-cover grid |
| Merch | Store down; no visible design line | Collection built on the logo, the Cross of Burgundy and mottos |
| Motion | None | Glyph-field animations of iconic images (see `iconography.md`) |
| Vector assets | Logo only as PNG | Redraw logo in SVG |

## Conclusion

Do **not** rebrand. Bring **evolutions**: same logo and burgundy, plus a full system (type, secondary colours, imprint, social templates, merch line, motion). Each proposal in `proposals/` pushes that system in a different direction.
