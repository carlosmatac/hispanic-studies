## Technical lessons from this session (save yourself hours)

- **Headless Chrome** for verification: `scrollTo` changes `scrollY` but **dispatches no `scroll` events** (dispatch them manually); CSS **animations/transitions don't advance after load** (check end state with durations forced to 0); `--dump-dom` returns only the top document; a test harness iframe must be **same-origin** (put `_t.html` inside the proposal folder, delete before committing); don't leave `scroll-behavior: smooth` on in the harness.
- **Never mix `performance.now()` with requestAnimationFrame timestamps.** Take t0 from the first frame callback and clamp t to [0,1]. Mixing them threw a map `viewBox` into the billions and made counters show −12252.
- **Reveals must fail open**: hidden state behind `.js-motion` set in `<head>`, removed by a timer if boot never finishes; reveal anything already scrolled past.
- **Absolutely positioned scroll steps add no height** — size the section from a `--steps` custom property.
- Each proposal is self-contained: if it reuses `o-atlas/map.js` it needs its own `.map` base CSS (an SVG sphere path without `fill: none` renders as a black slab).
- **CDN React must be dynamic-imported** — a static import let an unreachable CDN take down the whole page.
- In Python string replacements, `assert old in s` — one silent no-op cost a debugging round.
- Map type and strokes must be sized via `--u` (user units per screen pixel, published by `map.js`) or they balloon when zooming.
